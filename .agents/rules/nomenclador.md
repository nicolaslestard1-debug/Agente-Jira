# Reglas del Nomenclador de Tareas (Monks Data / Consult + TSE)

Hoja de referencia oficial: `https://docs.google.com/spreadsheets/d/128mKsJdJ_gzIhFJAAHOnpFbSxB50HnVafuZ6FulBmbI/edit?gid=1954649812#gid=1954649812`

Al crear tareas o épicas en Jira, se debe seguir estrictamente este nomenclador:

## Estructura General
- **Épica**: Nomenclatura épica (ej. `Auditorías - {detalle}`, `Taggeos - {detalle}`, `Armado de Guías - {detalle}`, `Gestión de la Cuenta`, `Planning Interno`).
- **Task / Subtask**: `{Prefijo} {Tarea Específica} - {Detalle del cliente o flujo}`.

## Prefijos Oficiales Principales
### Auditorías (ADT)
- `ADT completa - {detalle}` (estructura + propiedades + eventos + Firebase + GTM)
- `ADT estructura de cuenta - {detalle}`
- `ADT propiedad - {detalle}` / `ADT propiedades - {detalle}`
- `ADT eventos - {detalle}`
- `ADT firebase - {detalle}`
- `ADT GTM - {detalle}`
- `ADT Pixeles - {detalle}`
- `ADT GCP - {detalle}`
- `ADT BQ - {detalle}`
- `ADT Push - {detalle}`

### Taggeo / Planes de Medición y Guías
- `Taggeo basico -` / `Taggeo intermedio -` / `Taggeo avanzado -`
- `PDM basico -` (Plan de medición hasta 10 eventos)
- `PDM intermedio -` (Plan de medición 10 a 25 eventos)
- `PDM avanzado -` (Plan de medición > 25 eventos)
- `GDI basico -` / `GDI intermedio -` / `GDI avanzado -` (Guía de implementación)
- `IEP basico -` / `IEP intermedio -` / `IEP avanzado -` (Implementación y testeo)
- `TT basico -` / `TT intermedio -` / `TT avanzado -` (Testeos)

### Dashboards (DB)
- `DB basico - {detalle}`
- `DB intermedio - {detalle}`
- `DB avanzado - {detalle}`

### Reuniones y Gestión
- `REUI - {detalle}` (Reuniones internas / syncs, ej. `REUI - Sync Monks`)
- `REUE - {detalle}` (Reuniones externas con cliente)
